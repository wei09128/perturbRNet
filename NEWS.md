# perturbRNet 0.1.0

- Added generic donor-aware pseudobulk aggregation for scRNA-seq and snRNA-seq.
- Added arbitrary edgeR contrast fitting and perturbation fingerprint creation.
- Added signed, ridge-regularized PRN construction.
- Added target-level net, gross, counterdirection, balance, and hidden
  compensation scores.
- Added explicit evidence-level labels to prevent causal overstatement.
- Added a minimal synthetic cancellation example.
